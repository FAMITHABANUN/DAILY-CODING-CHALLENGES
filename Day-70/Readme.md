# Day-70

## Problems Solved

### 1. Squares of a Sorted Array
- **File:** `Squares of sorted array.java`
- **Platform:** LeetCode
- **Concept:** Array / Two Pointers
- **Approach:** Compare the absolute values from both ends and place the larger square from the back of the result array.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

### 2. Valid Mountain Array
- **File:** `Valid mountain array.java`
- **Platform:** LeetCode
- **Concept:** Array / Two Pointers
- **Approach:** Move upward while elements are increasing and then move downward while elements are decreasing.
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
