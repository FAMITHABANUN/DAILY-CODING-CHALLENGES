# Day 16 - LeetCode Solutions

## Problem 1

- Problem Name: Best Time to Buy and Sell Stock
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Traverse the array once while keeping track of the minimum stock price.
- Calculate the maximum profit that can be obtained.

### Time Complexity
- O(n)

### Space Complexity
- O(1)

## Problem 2

- Problem Name: Third Maximum Number
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Track the first, second, and third distinct maximum numbers.
- Return the third maximum if it exists; otherwise, return the maximum number.

### Time Complexity
- O(n)

### Space Complexity
- O(1)
