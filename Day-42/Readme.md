## 📌 Problems Solved

### 1. Binary Number with Alternating Bits

* **Problem:** Check whether a given number has alternating `0`s and `1`s in its binary representation.
* **Concept Used:** Bit Manipulation
* **Key Idea:** Compare adjacent bits to make sure they are always different.
* **Language:** Java

### 2. Self Dividing Numbers

* **Problem:** Find all self-dividing numbers within a given range.
* **Concept Used:** Mathematics / Digit Manipulation
* **Key Idea:** A number is self-dividing if it is divisible by each of its digits and contains no zero digit.
* **Language:** Java
