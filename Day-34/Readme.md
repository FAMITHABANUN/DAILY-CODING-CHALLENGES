## Problem 1

* Problem Name: Construct the Rectangle
* Platform: LeetCode
* Language: Java
* Difficulty: Easy
* Approach: Find the length and width of a rectangle whose area equals the given number. Start from the square root of the area and find the closest pair of factors.
* Time Complexity: O(√n)
* Space Complexity: O(1)
