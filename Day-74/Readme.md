# Day-74

## Problems Solved

### 1. Find K Pairs with Smallest Sums
- **File:** `Find K Pairs with Smallest Sums.java`
- **Platform:** LeetCode
- **Concept:** Heap / Priority Queue
- **Approach:** Use a min-heap to repeatedly select the smallest pair sums.
- **Time Complexity:** O(k log k)
- **Space Complexity:** O(k)

### 2. Reorder List
- **File:** `Reorder List.java`
- **Platform:** LeetCode
- **Concept:** Linked List
- **Approach:** Find the middle, reverse the second half, and merge both halves.
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
