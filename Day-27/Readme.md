# Day 27 - LeetCode Solutions

## Problem 1

- Problem Name: Find Customer Referee
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Retrieve customer names whose referee_id is not 2 or is NULL using the WHERE clause.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: N-th Tribonacci Number
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use Dynamic Programming by iteratively computing each Tribonacci number from the previous three values.
- Time Complexity: O(n)
- Space Complexity: O(1)
