# Day 18 - LeetCode Solutions

## Problem 1

- Problem Name: Maximum Number of Balloons
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Count the frequency of each character in the given string.
- Determine how many times the word "balloon" can be formed using those characters.

### Time Complexity
- O(n)

### Space Complexity
- O(1)

## Problem 2

- Problem Name: Minimum Increment to Make Array Unique
- Platform: LeetCode
- Language: Java
- Difficulty: Medium

### Approach
- Sort the array and increment duplicate or smaller elements until all elements become unique.
- Calculate the total number of increments required.

### Time Complexity
- O(n log n)

### Space Complexity
- O(1)

---

## Problem 3

- Problem Name: Maximum Product of Two Elements in an Array
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy

### Approach
- Find the two largest elements in the array.
- Compute the product using the formula (max1 - 1) × (max2 - 1).

### Time Complexity
- O(n)

### Space Complexity
- O(1)
