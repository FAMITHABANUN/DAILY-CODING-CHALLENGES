# Day 26 - LeetCode Solutions

## Problem 1

- Problem Name: Reverse String
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use the two-pointer technique to swap characters from both ends of the array until they meet in the middle.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Triangle Judgement
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Use a CASE statement to check whether the given sides satisfy the triangle inequality theorem (`x + y > z`, `x + z > y`, and `y + z > x`).
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Word Pattern
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use a HashMap to maintain a one-to-one mapping between pattern characters and words while ensuring consistency.
- Time Complexity: O(n)
- Space Complexity: O(n)
