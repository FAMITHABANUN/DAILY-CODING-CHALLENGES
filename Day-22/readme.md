# Day 22 - LeetCode Solutions

## Problem 1

- Problem Name: Consecutive Numbers
- Platform: LeetCode
- Language: SQL
- Difficulty: Medium
- Approach: Use self joins or window functions to identify numbers that appear at least three times consecutively.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Contains Duplicate
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use a HashSet to detect whether any element appears more than once.
- Time Complexity: O(n)
- Space Complexity: O(n)

## Problem 3

- Problem Name: Distribute Candies
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Count the distinct candy types using a HashSet and return the minimum of distinct types and n/2.
- Time Complexity: O(n)
- Space Complexity: O(n)
