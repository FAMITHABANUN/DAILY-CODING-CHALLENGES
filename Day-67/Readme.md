# Day-67

## Problems Solved

### 1. Longest Harmonious Subsequence
- **File:** `Longest harmonious subsequence.java`
- **Platform:** LeetCode
- **Concept:** Array / HashMap
- **Approach:** Count the frequency of each number and find the maximum length of a subsequence containing two numbers whose difference is exactly 1.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

### 2. Set Mismatch
- **File:** `Set mismatch.java`
- **Platform:** LeetCode
- **Concept:** Array / Frequency Counting
- **Approach:** Find the duplicated number and the missing number by checking the frequency of each value.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
