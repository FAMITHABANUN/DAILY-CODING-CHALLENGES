# Day 25 - LeetCode Solutions

## Problem 1

- Problem Name: Best Time to Buy and Sell Stock
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Traverse the array once while keeping track of the minimum stock price seen so far and update the maximum profit.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Maximum Subarray
- Platform: LeetCode
- Language: Java
- Difficulty: Medium
- Approach: Use Kadane's Algorithm to continuously track the maximum subarray sum ending at each position.
- Time Complexity: O(n)
- Space Complexity: O(1)

---

## Problem 3

- Problem Name: Rising Temperature
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Use a self join to compare each day's temperature with the previous day's temperature and return the required IDs.
- Time Complexity: O(n)
- Space Complexity: O(1)
