### 1. Find Common Characters
- **File:** `Find Common Characters.java`
- **Platform:** LeetCode
- **Concept:** String / Frequency Array
- **Approach:** Store character frequencies for each word and keep the minimum frequency.
- **Time Complexity:** O(n × k)
- **Space Complexity:** O(1)

### 2. Remove Outermost Parentheses
- **File:** `Remove Outermost Parentheses.java`
- **Platform:** LeetCode
- **Concept:** String / Stack Logic
- **Approach:** Track nesting depth and remove the outermost parentheses of each primitive substring.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
