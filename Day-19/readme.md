# Day 19 - LeetCode Solutions

## Problem 1

- Problem Name: Count Partitions with Even Sum Difference
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Calculate the total sum of the array, then iterate through possible partition points while maintaining the left sum. Check whether the difference between left and right sums is even.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: House Robber
- Platform: LeetCode
- Language: Java
- Difficulty: Medium
- Approach: Use Dynamic Programming to determine the maximum amount that can be robbed without robbing two adjacent houses.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Left and Right Sum Differences
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Compute the total sum first, then traverse the array while maintaining the left sum to calculate the absolute difference at each index.
- Time Complexity: O(n)
- Space Complexity: O(1)
