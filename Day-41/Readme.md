## 📌 Problems Solved

### 1. Nim Game

* **Problem:** Determine whether the first player can win the Nim Game.
* **Concept Used:** Bit Manipulation
* **Key Idea:** A position with `n % 4 == 0` is losing for the first player.
* **Language:** Java

### 2. Power of Four

* **Problem:** Check whether a given number is a power of 4.
* **Concept Used:** Bit Manipulation / Mathematics
* **Key Idea:** A positive number is a power of 4 if it is a power of 2 and its set bit is in the correct position.
* **Language:** Java
