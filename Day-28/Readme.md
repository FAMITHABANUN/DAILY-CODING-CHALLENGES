# Day 28 - LeetCode Solutions

## Problem 1

- Problem Name: Class with at Least 5 Students
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Group the records by class and use the HAVING clause to filter classes with at least 5 students.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Linked List Cycle
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use Floyd's Cycle Detection (Slow and Fast Pointers) to determine whether a cycle exists in the linked list.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Valid Palindrome II
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use the two-pointer technique and allow at most one character deletion to verify if the string can become a palindrome.
- Time Complexity: O(n)
- Space Complexity: O(1)
