# Day 24 - LeetCode Solutions

## Problem 1

- Problem Name: Biggest Single Number
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Group the numbers, filter those appearing only once using HAVING COUNT(*) = 1, and return the maximum value.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Sort Array By Parity
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
