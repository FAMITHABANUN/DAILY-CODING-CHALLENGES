# Day 36 - LeetCode Solutions

## Problem 1

* Problem Name: Unique Paths
* Platform: LeetCode
* Language: Java
* Difficulty: Medium
* Approach: Use dynamic programming to calculate the number of unique ways to reach each cell. Each cell gets the sum of the paths from the cell above and the cell to the left.
* Time Complexity: O(m × n)
* Space Complexity: O(n)
