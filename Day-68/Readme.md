## Problems Solved

### 1. Find Pivot Index
- **File:** `Find pivot index.java`
- **Platform:** LeetCode
- **Concept:** Array / Prefix Sum
- **Approach:** Calculate the total sum and compare the left sum with the right sum for each index.
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### 2. Search in a Binary Search Tree
- **File:** `Search in a binary search tree.java`
- **Platform:** LeetCode
- **Concept:** Binary Search Tree / Recursion
- **Approach:** Compare the target value with the current node and move to the left or right subtree accordingly.
- **Time Complexity:** O(h)
- **Space Complexity:** O(h)
