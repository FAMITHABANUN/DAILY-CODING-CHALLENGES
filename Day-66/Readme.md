# Day-66

## Problems Solved

### 1. Toeplitz Matrix
- **File:** `Toeplitz matrix.java`
- **Platform:** LeetCode
- **Concept:** 2D Array / Matrix
- **Approach:** Compare each element with the element diagonally above it.
- **Time Complexity:** O(m × n)
- **Space Complexity:** O(1)

### 2. Uncommon Words from Two Sentences
- **File:** `Uncommon words form two sentences.java`
- **Platform:** LeetCode
- **Concept:** String / HashMap
- **Approach:** Count the frequency of every word from both sentences and find the words that occur exactly once.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
