# Day 31 - LeetCode Solutions

## Problem 1

- Problem Name: Number of Lines To Write String
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Traverse each character and keep track of the current line width. When adding a character exceeds the limit, start a new line.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Project Employees I
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Use JOIN and AVG() to calculate the average experience years of employees working on each project.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Relative Sort Array
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use a frequency array to count elements and place elements according to the order given in arr2, followed by the remaining elements in ascending order.
- Time Complexity: O(n + m + k)
- Space Complexity: O(k)
