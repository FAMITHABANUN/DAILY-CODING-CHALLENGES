# Day 23 - LeetCode Solutions

## Problem 1

- Problem Name: Contains Duplicate II
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Use a HashMap to store the last index of each element and check if the index difference is within k.
- Time Complexity: O(n)
- Space Complexity: O(n)

## Problem 2

- Problem Name: Game Play Analysis I
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Use GROUP BY with the MIN() function to find each player's first login date.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Largest Perimeter Triangle
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Sort the array in descending order and check the triangle inequality to find the maximum perimeter.
- Time Complexity: O(n log n)
- Space Complexity: O(1)
