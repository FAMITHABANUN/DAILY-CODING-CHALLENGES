# Day 21 - LeetCode Solutions

## Problem 1

- Problem Name: Complement of Base 10 Integer
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Generate a bitmask based on the number of bits in the integer.
- Perform XOR operation with the original number to obtain its complement.

### Time Complexity
- O(log n)

### Space Complexity
- O(1)

## Problem 2

- Platform: LeetCode
- Language: Java
