## Problems Solved

### 1. Leaf-Similar Trees
- **File:** `Leaf-Similar Trees.java`
- **Platform:** LeetCode
- **Concept:** Binary Tree / DFS
- **Approach:** Traverse both trees, collect their leaf nodes, and compare the sequences.
- **Time Complexity:** O(n + m)
- **Space Complexity:** O(n + m)

### 2. Middle of the Linked List
- **File:** `Middle of the Linked List.java`
- **Platform:** LeetCode
- **Concept:** Linked List / Two Pointers
- **Approach:** Use slow and fast pointers to find the middle node.
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
