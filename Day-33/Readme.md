# Day 33 - LeetCode Solutions

## Problem 1

- Problem Name: Largest Triangle Area
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Calculate the area of every possible triangle using the given points and keep track of the maximum area.
- Time Complexity: O(n³)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Remove Linked List Elements
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Traverse the linked list and remove all nodes whose value matches the given value. A dummy node is used to handle removal of the head node easily.
- Time Complexity: O(n)
- Space Complexity: O(1)
