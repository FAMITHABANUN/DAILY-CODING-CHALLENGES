# Day 30 - LeetCode Solutions

## Problem 1

- Problem Name: Fraction to Recurring Decimal
- Platform: LeetCode
- Language: Java
- Difficulty: Medium
- Approach: Use long division and a HashMap to track remainders and identify repeating decimal parts.
- Time Complexity: O(n)
- Space Complexity: O(n)

## Problem 2

- Problem Name: Patients With a Condition
- Platform: LeetCode
- Language: SQL
- Difficulty: Easy
- Approach: Use the LIKE operator to find patients whose conditions contain the required medical code.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 3

- Problem Name: Subtract the Product and Sum of Digits of an Integer
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Extract each digit using modulo and division, calculate the product and sum of the digits, and return their difference.
- Time Complexity: O(log n)
- Space Complexity: O(1)
