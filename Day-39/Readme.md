# Day 39 - LeetCode Solutions

## Problem 1

* Problem Name: Maximum Product Subarray
* Platform: LeetCode
* Language: Java
* Difficulty: Medium
* Approach: Keep track of the current maximum and minimum products because a negative number can turn the minimum product into the maximum. Update the overall maximum while traversing the array.
* Time Complexity: O(n)
* Space Complexity: O(1)
