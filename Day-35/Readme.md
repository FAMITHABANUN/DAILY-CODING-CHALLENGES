# Day 35 - LeetCode Solutions

## Problem 1

* Problem Name: Spiral Matrix
* Platform: LeetCode
* Language: Java
* Difficulty: Medium
* Approach: Traverse the matrix in spiral order by maintaining four boundaries: top, bottom, left, and right. Move across each boundary and update it after every traversal.
* Time Complexity: O(m × n)
* Space Complexity: O(1)
