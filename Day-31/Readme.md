# Day 31 - LeetCode Solutions

## Problem 1

- Problem Name: Odd and Even Transactions
- Platform: LeetCode
- Language: SQL
- Difficulty: Medium
- Approach: Use CASE statements with SUM() to calculate the total amount of odd and even transactions for each date.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Problem 2

- Problem Name: Reshape the Matrix
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Convert the matrix elements into a sequence and fill them into the new matrix row by row.
- Time Complexity: O(m × n)
- Space Complexity: O(m × n)

## Problem 3

- Problem Name: Transpose Matrix
- Platform: LeetCode
- Language: Java
- Difficulty: Easy
- Approach: Create a new matrix and place each element at the swapped row and column positions.
- Time Complexity: O(m × n)
- Space Complexity: O(m × n)
