# Day 20 - LeetCode Solutions

## Problem 1

- Problem Name: Is Subsequence
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Use two pointers to compare characters of both strings.
- Check whether all characters of the first string appear in order in the second string.

### Time Complexity
- O(n)

### Space Complexity
- O(1)

## Problem 2

- Problem Name: Maximum 69 Number
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Traverse the digits of the number.
- Change the first occurrence of '6' to '9' to obtain the maximum possible value.

### Time Complexity
- O(n)

### Space Complexity
- O(1)

## Problem 3

- Problem Name: Number Complement
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Create a bitmask for the given number.
- Flip all the bits within the valid range to obtain its complement.

### Time Complexity
- O(log n)

### Space Complexity
- O(1)

---

## Problem 4

- Problem Name: Reverse String
- Platform: LeetCode
- Language: Java
- Difficulty: Easy

### Approach
- Use two pointers to swap characters from both ends of the array.
- Continue until the pointers meet.

### Time Complexity
- O(n)

### Space Complexity
- O(1)
